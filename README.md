# Marketing Campaign Performance Dashboard
Marketing Campaign Performance Dashboard built with Microsoft Power BI

This repository contains a Microsoft Power BI dashboard designed to track and analyze marketing campaign performance.

## Dashboard Features

*   **Campaign Tracking:** Monitors total campaigns, impressions, and clicks.
*   **Performance Metrics:** Displays CTR, Average ROI, and Total Acquisition Cost.
*   **Visualizations:**
    *   Click Over Time
    *   CTR by Channel Used
    *   ROI by Campaign Type
    *   Total Clicks by Location
    *   Impressions by Company
*   **Interactive Filters:** Allows users to filter data by specific companies.

## Data Sources

The dashboard uses data from marketing campaigns (e.g., Website, Email, YouTube, Facebook, Instagram, Google Ads).

## How to Use

1.  Download the `.pbix` file from this repository.
2.  Open the file in Microsoft Power BI Desktop.
3.  Refresh the data to load the latest campaign metrics.
